USV COLREGs Simulator v1.6.2

Delivery focus:
- Speed commands use mission initial speed V0 as a fixed anchor; tactical setpoints are bounded to [0.5 V0, 1.5 V0], additionally narrowed by the vessel's configured min/max speed.
- MPC exposes hold, +/-25%, and +/-50% speed levels. Replanning does not accumulate/rachet the setpoint.
- Actual acceleration/deceleration remain rate-limited by length-dependent vessel parameters and first-order surge lag.
- Rule 14 head-on: active collision-risk candidates are constrained to a noticeable starboard alteration.
- Rule 15/16 right-side give-way: the ownship gives way and predicted crossing-ahead trajectories are rejected when circumstances admit a safe astern route; a substantial course alteration OR explicit speed reduction is accepted. Rule 15/16 do not force a starboard turn.
- Rule 17 stand-on: hold course and speed before the intervention stage; apply Rule 17(c) port-turn preference only for port-side contact when circumstances admit.
- Appendices C and D encounter buckets and scenarios are better represented, including right/left beam contacts; Appendix A Table A.1 angles are soft initial-angle references, not hard COLREG requirements.
- 5-degree course resolution and five speed levels create 125 action candidates.

SDA boundary and outcome:
- Map circles are centered on each active target and use the same Appendix-B SDA radius used by the actual-distance failure check; SDApref remains separate for risk/intervention timing.
- Actual minimum centre-to-centre separation is computed over each control interval by swept relative-motion segments. If it is strictly below the current encounter SDA, the target is latched as an SDA failure for the run; the run continues to preserve the full trajectory.
- GUI status, per-target metrics, logs and evaluation CSV report the SDA breach, violating target IDs, minimum measured separation and SDA margin.
- Appendix-B tables B.1-B.3 and Table B.4 vessel-type factors are included. Non-tabulated lengths are linearly interpolated/extrapolated and marked estimated. Crossing/beam uses the larger bow/stern row as a conservative boundary while the pass position is not locked. Unknown/following uses a visibly marked conservative estimated envelope because Appendix B has no dedicated row for those cases.
- Appendix B is informative example data, not a universal mandatory radius for all ship types/waters; the project uses it as its default configured SDA reference.

PPO tactical authority / route recovery fix (v1.6.2):
- PPO is authorized to select actions only while the engine is in an active collision-avoidance manoeuvre window established by the shared rule/risk trigger. Rule 17 stand-on intervention is included when its configured intervention threshold is reached.
- During passive monitoring, the action mask is a singleton containing the deterministic rule/MPC baseline candidate. This prevents PPO from initiating an untriggered heading/speed change.
- During route recovery and post-recovery cruise, PPO is gated out; the same deterministic MPC baseline that is optimized for cross-track convergence controls recovery.
- Training action masks and deployment action masks use the same phase gate. Candidate-v4 action count, observation size and actor-critic architecture are unchanged; v1.6.1 candidate-v4 checkpoints remain structurally compatible.
- Encounter start, encounter-clear-to-recovery transition and newly involved target events invalidate held policy commands and force immediate replanning, rather than allowing an old PPO course command to persist until the next 10 s update.
- GUI and step logs expose policy_source, policy_action_authorized, policy_gate_reason and maneuver_start_time_s.
