## 全局契约

- 固定21个候选槽：航向偏移 `[0,10,20,35,-10,-20,-35]` 度 × 速度模式 `[hold,slow,accelerate]`；索引0保持航向/速度。候选相对会遇起始航向，驶过让清后用航线LOS。
- 每轮先预测一次候选，统一规则对所有目标约束，PPO或确定性基线选择同一候选库；执行首段不得再默默改变候选含义。
- 所有候选无解时保留最小违反恢复动作，显式标记不可行及干预，训练保存提议动作和原log-prob。
- 环境物理控制周期2秒、策略周期10秒；训练通过同一engine推进策略周期，不使用10秒粗积分替代。
- 目标默认常速度预测，无未来脚本泄漏；oracle仅为显式对照。目标实际更新与oracle共用积分器。
- 旧权重版本拒绝加载，训练/验证/测试划分写入checkpoint；无独立测试证据不声称收益提高。
