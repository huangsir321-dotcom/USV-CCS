## v1.6.0 补充追踪：速度与规则动作

| 来源 | 工程处理 | 限制/说明 |
|---|---|---|
| 1972 COLREGs Rule 8 | 及早、明显、避免连续小幅变更；优先对预测轨迹做全时域检查 | 10° 动作可见性门槛为工程参数，Rule 8 本身未给出固定角度 |
| Rule 13 | 追越身份持续到驶过让清；通过侧由路径安全性选择 | 条文未指定追越必须从哪一舷通过 |
| Rule 14 | 对遇风险时限制为右转候选 | 具体角度依环境和安全性；20° 只是 GB/T 表 A.1 开阔水域参考值 |
| Rule 15/16 | 右舷来船时本船让路；预测轨迹优先从船尾通过；通过明显改向或明确减速实现及早、大幅度行动 | Rule 15/16 不规定交叉让路船必须右转；“避免船首通过”有“环境许可”前提；无安全候选时进入最低风险回退并记录原因 |
| Rule 17 | 直航阶段优先保向保速，责任/风险升级时允许必要行动 | 直航船并非任何时候都绝对不动作；紧迫情形需按 Rule 17(b) 行动 |
| 航速限制 | 指令目标限制为初始 V0 的 50%–150%，再受 config min/max 限制；实际 u-dot 由长度依赖动力学限制 | ±50% 是该仿真器的工程速度包络，不是 COLREGs 中规定的航速百分比 |
| GB/T 46851-2025 Appendix A Table A.1 | 对遇 20°、追越 10°、右舷小/大角度交叉 30°/60° 作为开阔水域软参考 | 附录为资料性内容；不同水域表格数值不同，不应写成通用强制角 |

## 重要解释

本表是研发实现追踪，不是标准符合性声明。标准附录 B 的完整表格需在下一轮从原文逐项录入并复核；当前 `sda.py` 仅采用部分示例组合。风险等级的简化实现不等于标准附录 A 算法。船舶动力学也需在取得具体船型数据后从简化 3-DOF 升级为可标定的 MMG 模型。
