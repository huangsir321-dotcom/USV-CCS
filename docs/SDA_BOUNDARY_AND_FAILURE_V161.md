# SDA安全边界与失败判定（v1.6.1）

## 1. 图形边界

- 每艘已识别会遇目标船绘制一个以目标船当前位置为圆心的圆。
- 圆半径严格使用该目标当前会遇分类所查得的 `SDA`（单位 m），不再使用 `SDApref`。
- `SDApref` 仍可用于风险干预时机计算；它是操纵/能见度余量后的理想安全距离，不是本次图上风险圆的半径。
- 圆的标签显示 `SDA xxx m`。船长不落在标准表格离散尺寸上时显示 `~`，表示采用插值/外推估值。
- 对遇、追越等表格子项按对应值查表。交叉/正横场景在尚未锁定实际通过位置时，圆半径采用附录 B“首/尾”两项中较大的 SDA，作为保守风险边界。
- 当前会遇未分类为附录 B 中的会遇情况（`none` / `following`）时，采用所有附录 B 示例条目中的保守最大估算值并标记 `~`，避免近距离未分类目标完全失去风险边界；这不是标准中的独立会遇行。

## 2. SDA数据来源

使用 GB/T 46851—2025 附录 B 表 B.1、B.2、B.3 的 100 m、200 m、300 m 散货船示例数据；包含对遇、右/左交叉、右/左正横、被追越、追越、右/左后追越、左/右后被追越及表内首/尾或过左/过右子项。其他船型按表 B.4 系数计算。

附录 B 标题为“安全会遇距离数据库示例”，属资料性附录。其自身允许系统根据实际船舶、能见度、会遇局面与操纵性合理设定 SDA。因此，项目将其作为默认示例数据库来源，不将其表值宣称为所有船型/水域的强制统一值。

标准表格离散点为本船船长 100/200/300 m、目标船船长 50/100/200/300 m。其余船长用相邻表值进行线性插值或外推，界面和日志标记为估算值。目标船类型系数使用表 B.4：LNG/危化品 1.50、集装箱 1.33、客船 1.20、油轮 1.36、其他船型 1.00。

## 3. 实际失败判定

- 对每个控制周期，使用本船与目标船在该周期的前后位置构造相对运动线段，计算该周期内**实际最小中心到中心距离**（swept separation），避免只在采样端点检查而漏掉两帧之间的最近点。
- 将该实际最小距离与该周期风险快照中的同一个 `SDA` 比较。
- 若 `actual_min_separation < SDA`，立即记录该目标发生 SDA 侵入；本案例的评估成功标记为“否”。等于 SDA 不判侵入。
- 失败标记在本回合内锁存，即使后续驶出圆或没有发生实体船体碰撞，也不会恢复为成功。
- 仿真不会因 SDA 侵入立刻停止，继续运行到终点/最大步数，以保留完整轨迹供分析；GUI 状态立即显示“避碰失败”。批量评估 CSV 输出违规目标、各目标实际最小会遇距离、SDA侵入时长和最小SDA裕度。

## 4. 解释

实体碰撞与 SDA 侵入是两种不同判定：实体碰撞按船体几何尺度计算；SDA 侵入是实际中心距进入标准示例安全会遇距离圈。可能发生“无实体碰撞但已经低于 SDA”的失败情况，这正是本版本增加的判据。
