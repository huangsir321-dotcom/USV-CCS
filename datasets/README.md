# Uploaded encounter dataset

This folder contains the user's original CSV case files and any preview PNGs present in the uploaded archives.

- `1t/`: 138 cases, one target row per CSV, UTF-8 BOM.
- `2t_0720/`: 99 cases, two target rows per CSV, GB18030/GBK-compatible encoding.
- `3t/`: 31 cases, three target rows per CSV, GB18030/GBK-compatible encoding.

Total: 268 initial encounter-state cases. The CSVs do not contain continuous trajectories or vessel dimensions. See `../docs/DATASET_INTEGRATION.md`.
